# VuloForm website

Marketing website for VuloForm, the drag-and-drop form builder for WordPress.

## See it locally

The whole site is one file, `index.html`, with no build step.

1. Download this repo (green **Code** button, then **Download ZIP**) and unzip it.
2. Double-click `index.html`. It opens in your browser.

To edit text or colours, open `index.html` in any text editor (VS Code, Notepad), save, and refresh the browser. Colours are at the top of the file under `:root`.

## See it online (GitHub Pages)

In this repo go to **Settings > Pages**, set **Source** to *Deploy from a branch*, pick `main` and `/ (root)`, and save. After a minute the site is live at https://buddhadebroy.github.io/VuloForm-website/
